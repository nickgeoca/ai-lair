# Multi-repository workspace

This directory contains the disposable repositories explicitly selected by the
user for this Hermes session. Each immediate child directory is an independent
Git repository.

Before claiming that a repository or file is unavailable, enumerate the
immediate child directories here and inspect the relevant repository with local
file or terminal tools. Do not infer availability from earlier conversation
turns or from public GitHub search results.

Work only inside the repositories present here. They are writable disposable
clones; commit changes separately in each repository when the user requests a
commit. The parent directory is only a workspace container and is not itself a
Git repository.
